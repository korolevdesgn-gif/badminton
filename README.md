# Бадминтон: прототип

Браузерная игра, вид сбоку, одиночка до 15. Волан летит по физике с квадратичным сопротивлением воздуха.

Играть: https://korolevdesgn-gif.github.io/badminton/

- **Против ИИ** — три уровня сложности.
- **Онлайн с другом**: один создаёт комнату и получает код из 4 символов, второй вводит код. Соединение напрямую через WebRTC (PeerJS).
- **Таблица побед**: имя при входе, победы над друзьями и над ИИ. Устройства обмениваются результатами при каждой онлайн-партии.

Управление: `A`/`D` бег, `W` прыжок, `Q` клир, `E` дроп, `S` смэш.
